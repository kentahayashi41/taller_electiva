# Registro de Videojuegos  ## Descripcion Aplicacion de consola desarrollada en C# que utiliza ADO.NET y SQLite para almacenar y consultar informacion de videojuegos.  ## Tecnologias utilizadas - C# - .NET - ADO.NET - SQLite - Microsoft.Data.Sqlite  ## Funcionalidades - Crear una base de datos SQLite. - Crear una tabla de videojuegos.
